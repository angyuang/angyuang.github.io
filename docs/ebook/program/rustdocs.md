# rust文档网
- [rust文档网](https://rustwiki.org/)

# Rust 程序设计语言
Rust 官方编著的 Rust 基本教程，也称 Rust Book，中文出版书名译作《Rust 权威指南》。
- [Rust 程序设计语言](https://rustwiki.org/zh-CN/book/)

# 通过例子学 Rust
每个小节都提供一个完整的 Rust 代码简例，通过这些例子可以轻松掌握 Rust 的各个知识点。
- [通过例子学 Rust](https://rustwiki.org/zh-CN/rust-by-example/)

# rustlings
Rust 小练习，Rust 官方推出的交互式练习工具，边阅读、修改和运行代码，边学习概念。
- [rustlings](https://rustwiki.org/zh-CN/rust-by-example/)

# Rust 参考手册
官方的 Rust 语言规范，涵盖 Rust 的最全面的规范内容，目前文档还未稳定，属于预览版。
- [Rust 参考手册](https://rustwiki.org/zh-CN/reference/)

# Rust 标准库
官方的 Rust 标准库，是可移植 Rust 软件的基础，标准库文档是开发过程中的必备内容。
- [Rust 标准库](https://rustwiki.org/zh-CN/std/)

# Rust Cookbook
Rust 官方图书，由一系列简单程序示例构成，展示了 Rust 实际开发场景的良好实践。
- [Rust Cookbook](https://rustwiki.org/zh-CN/rust-cookbook/)

# Cargo 手册
Cargo 是 Rust 的包管理器，通过本手册全面了解如何构建 Rust 程序和大型项目。
- [Cargo 手册](https://rustwiki.org/zh-CN/cargo/)

# Rust 版本指南
了解 Rust 版本有关内容，比如初版（Rust 2015）、Rust 2018 版和 2021 版，掌握如何迁移代码。
- [Rust 版本指南](https://rustwiki.org/zh-CN/edition-guide/)

# rustdoc 手册
学习 rustdoc 命令和使用 cargo doc 来生成漂亮的 Rust crate 的帮助文档，更好地管理和上传项目 API 文档。
- [rustdoc 手册](https://rustwiki.org/zh-CN/rustdoc/)


# rustc 手册
深入学习 rustc 命令行，熟悉 Rust 编译器的可用选项，构建强大的 Rust 程序。
- [rustc 手册](https://rustwiki.org/zh-CN/rustc/)


# Rust 编译错误索引表

- [Rust 编译错误索引表](https://rustwiki.org/zh-CN/error-index/)

Rust 中文资源和配套措施，相关翻译指引的范，以及中文翻译项目组的社区运作说明等。
